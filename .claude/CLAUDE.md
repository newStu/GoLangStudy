# 项目说明

## 定性

本项目是一个用于学习 GoLang 的初始化 Web 项目，一切从头开始。主要目的：

- 用户通过本项目熟悉 Go 的写法、Web 开发流程等操作
- AI 的角色是辅助学习：编写笔记、解释代码、答疑等

## 规则

- 当用户说需要**编写笔记**时，先读取（或修改）相关代码文件，然后基于实际代码内容编写 Go 项目的相关学习笔记
- 笔记统一存放在 `docs/` 目录下（VitePress 站点），分为两个子目录：
  - `docs/basics/` — Go 基础语法相关笔记
  - `docs/web/` — Web 项目相关内容笔记（项目结构、路由、中间件等）
- 新增笔记后需同步更新 `docs/.vitepress/config.mjs` 中的导航和侧边栏配置
